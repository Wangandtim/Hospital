# 分诊预约 Agent 验收清单

验收时间：2026-11-16，环境：本地 `hospital-api`（18080）+ MySQL `hospital_db`。

## 安全
- [x] 红旗样例 100% 不进入锁号/预约链路（`胸痛伴大汗，喘不上气` → `RED_FLAG`，无 recommendation，bookingAllowed=false）
- [x] 否定词（没有胸痛/不喘）不误触发红旗（`没有胸痛，就是有点咳嗽` → 正常路由呼吸内科，未触发红旗）
- [x] 匿名访问 `/api/triage/**` 返回 401（实测匿名 assess = 401）
- [x] 患者不能读取/操作他人 triage 会话（他人会话 detail / lock 均返回「无权操作他人的分诊记录」）
- [x] 替长辈问诊不把老人挂号到子女档案（账号 35 岁 + 长辈 78 岁 → bookingAllowed=false 且有明确原因）

## 正确性
- [x] HIGH ≥0.90，MEDIUM 0.70–0.90，LOW <0.70（实测 0.97 / 0.82 / 0.25）
- [x] HIGH 必须满足 2 个具体关键词 + 时长/伴随 + 首位≥次位2倍 + 无年龄段/孕产未知/科室竞争歧义，否则封顶 MEDIUM
- [x] 年龄段估算一律封顶 MEDIUM（同症状先用 ageBand → 0.89 MEDIUM，补精确年龄后 → 0.97 HIGH）
- [x] 科室命中与真实科室一致，非门诊科室不参与路由（呼吸/消化/内分泌/妇产科实测命中；急诊/放射/检验等已排除）
- [x] 专家三档与年龄/慢病/复查关键词一致（`血糖高，糖尿病很多年了，想复查` → REQUIRED）
- [x] 专家号不可用时降级且有明确提示（推荐普通号 + notices 说明可申请转诊）
- [x] 医院评分四维权重与硬过滤符合 Spec（实测推荐分 46，硬过滤排除无号/停用/过期时段）

## 信息不全
- [x] 年龄缺失 → NEED_PROFILE，只问年龄（missing=age）
- [x] 性别缺失 → NEED_PROFILE，只问性别（missing=gender）
- [x] 姓名/手机缺失不阻塞分诊，付款前引导完善
- [x] 既往史缺失只降置信度，不阻塞（同一症状 0.82 → 0.77，并写入判断依据）
- [x] 年龄段补全后置信度扣减并有提示（evidence: age_band）
- [x] 长辈口语长句可提炼：剔除铺垫词 + 口语同义词归一（实测「哎呀…脑袋晕乎乎的…吃不下饭」→ 0.88 MEDIUM 命中神经内科）
- [x] LOW 提供结构化按钮追问（部位/时长/伴随），补充后升至 HIGH 0.97

## 资源与幂等
- [x] 锁号 TTL 10 分钟，过期 60 秒内自动释放并恢复号源（改过期时间后 60 秒内 status=0/EXPIRED，booked_count 2→1）
- [x] 同一患者同时只有一个有效锁（锁新会话前自动释放其他有效锁）
- [x] 同一 triageId 重复锁号返回同一锁（实测 lockId 一致）
- [x] book 不再扣减号源；重复 book 返回同一预约（alreadyBooked=true，appointmentId 一致）
- [x] 已出单后重复锁号返回同一预约，不再新建锁（lock 表仅一条已消费记录）
- [x] 锁号后禁止再改年龄/性别（返回「号源已为你保留」）
- [x] 取消预约正常恢复号源（`AppointmentService` 取消时置 status=0 并回补 `booked_count`；本次已核对代码，建议上线前回归一次）
- [x] 会话过期归档：每天 03:15 将超 30 天未完成会话置 `EXPIRED`，不再返回推荐且拒绝锁号/确认
- [x] confirm 对 `BOOKED/LOCKED/REJECTED/EXPIRED` 拒绝，reject 只释放本会话锁且不改变已出单会话

## 前端
- [x] 标准模式：高置信度仅「去付款」，中置信度可改口（continue / 不是这个科室 / 补充症状）
- [x] 长辈模式首页主按钮为「语音 Agent 预约」，进入首屏是大话筒 + 长辈提示
- [x] 按住话筒可录音、松开结束；未配置 ASR 时展示常见不适按钮且不伪造识别
- [x] 语音转写网关 `POST /api/voice/transcribe`：未配置返回 enabled=false，前端自动降级；配置 `hospital.asr.url` 即启用（OpenAI 兼容协议）
- [x] 识别成功先大字复述「您说的是不是…」，确认后才判断；低置信或无有效症状直接降级为按钮
- [x] 方言词表覆盖四川/重庆（脑壳昏、肚皮疼）、粤语（肚屙、唔舒服）、河南/山东（肚里疼、不得劲儿）、东北（脑袋瓜子疼）；实测两个方言句均路由正确
- [x] 硅基流动 ASR 实测通过：TTS 中文语音 → 转写「我这两天老是咳嗽，还有点低烧，晚上睡不好觉」→ 分诊 HIGH 0.97 命中呼吸内科
- [x] 无效音频：网关返回 success=false / enabled=true，前端提示改用按钮，不会产出错误结论
- [x] 启用配置：`HOSPITAL_ASR_URL`、`HOSPITAL_ASR_TOKEN`、`HOSPITAL_ASR_MODEL`（默认 `FunAudioLLM/SenseVoiceSmall`），已写入用户环境变量
- [x] 长辈模式不显示置信度数字，隐藏倒计时数字，保留「号源为你保留中」
- [x] 低置信度预约入口关闭，有追问与人工出口
- [x] 急诊页无「返回预约」，120 可一键拨出
- [x] 首页（标准卡片 + 长辈主按钮）/设置两处入口可进入分诊页
- [x] 进入分诊页时若本地有 2 小时内未完成会话，提示「继续上次分诊」，按 `sessionStatus` 恢复；出单/重填/拒绝后清理本地记录
