## ⚠️ 问题 2：微信登录问题 - wx.getUserProfile 已废弃

### 问题原因
`wx.getUserProfile` 接口在 2021年4月后已被微信废弃，不再支持获取用户昵称和头像！

### 解决方案：简化登录流程

**修改文件**：`hospital-miniprogram/app.js:55-102`

将 `login()` 方法替换为：

```javascript
login() {
  return new Promise((resolve, reject) => {
    wx.login({
      success: (loginRes) => {
        // 使用简化登录，不需要获取用户信息
        this.requestSimpleLogin(loginRes.code)
          .then(resolve)
          .catch(reject);
      },
      fail: reject
    });
  });
},

requestSimpleLogin(code) {
  return new Promise((resolve, reject) => {
    wx.request({
      url: this.globalData.baseUrl + '/api/wechat/login',
      method: 'POST',
      data: {
        code: code,
        nickname: '微信用户',
        avatarUrl: ''
      },
      success: (res) => {
        if (res.statusCode === 200) {
          this.globalData.token = res.data.token;
          this.globalData.openid = res.data.openid;
          this.globalData.hasPatientInfo = res.data.hasPatientInfo;
          
          wx.setStorageSync('token', res.data.token);
          wx.setStorageSync('openid', res.data.openid);
          wx.setStorageSync('hasPatientInfo', res.data.hasPatientInfo);
          
          resolve(res.data);
        } else {
          reject(res);
        }
      },
      fail: reject
    });
  });
}
```
