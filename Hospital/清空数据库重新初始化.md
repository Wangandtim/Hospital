# 清空数据库并重新初始化（解决乱码问题）

## 🎯 问题分析

从控制台日志看到：
- ✅ API 请求成功（statusCode: 200）
- ✅ 数据已返回
- ❌ 数据是乱码（中文显示异常）

**原因**：数据库中的数据本身是用错误的编码存储的！

---

## 🔧 解决方案

### 步骤 1：停止后端服务

```bash
# 找到占用 8080 的进程
netstat -ano | findstr :8080
# 停止它（替换 PID）
taskkill /F /PID <进程号>
```

---

### 步骤 2：清空数据库

使用 MySQL 客户端（Navicat、MySQL Workbench、或命令行）连接到 MySQL，执行以下 SQL：

```sql
-- 切换到 hospital_db 数据库
USE hospital_db;

-- 清空所有表（按顺序避免外键约束）
DELETE FROM appointment;
DELETE FROM schedule;
DELETE FROM doctor;
DELETE FROM patient;
DELETE FROM department;
DELETE FROM wechat_user;
DELETE FROM nearby_hospital;
```

**或者更简单的方法 - 直接重建数据库**：

```sql
-- 删除旧数据库
DROP DATABASE IF EXISTS hospital_db;

-- 创建新数据库（使用 utf8mb4 编码）
CREATE DATABASE hospital_db 
CHARACTER SET utf8mb4 
COLLATE utf8mb4_unicode_ci;

-- 使用新数据库
USE hospital_db;
```

---

### 步骤 3：重新启动后端

```bash
cd hospital-api
mvn spring-boot:run
```

**启动时应该看到**：
```

✓ 排班数据初始化完成（20条排班）

西安欧亚学院门诊部数据检查完成！

```

---

### 步骤 4：验证数据

用浏览器访问测试：
- http://localhost:8080/api/departments
- http://localhost:8080/api/doctors

应该能看到**正常的中文**，不再是乱码！

---

### 步骤 5：刷新小程序

在微信开发者工具中点击「编译」，现在应该能看到：
- ✅ 首页显示科室和医生
- ✅ 中文正常显示
- ✅ 可以正常进入预约流程

---

## 📋 已完成的配置更新

✅ `application.properties` 已更新：
- 字符编码：`utf8mb4`（更好的中文支持）
- 添加了：`useSSL=false`

---

## 💡 如果还是乱码

请检查：
1. 数据库本身的字符集设置
2. 数据库表的字符集设置
3. MySQL 服务器的默认字符集

---

## 快速命令总结

```bash
# 1. 停止后端
taskkill /F /PID <8080端口的进程号>

# 2. 用 MySQL 客户端清空或重建数据库

# 3. 重新启动后端
cd hospital-api
mvn spring-boot:run

# 4. 刷新小程序
```
