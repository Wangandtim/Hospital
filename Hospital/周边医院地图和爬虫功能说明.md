# 周边医院地图和爬虫功能使用说明

---

## ✅ 已完成的功能

### 1. ✅ 地图组件已添加
- 在周边医院页面顶部显示地图
- 自动定位当前位置
- 医院标记点显示
- 点击标记点可以查看医院详情

### 2. ✅ Python 爬虫服务已集成
- 直接调用 Python 爬虫服务（http://localhost:5000）
- 获取周边医院信息
- 包含模拟数据（西安交通大学一附院、陕西省人民医院、欧亚学院门诊部）

---

## 🚀 使用步骤

### 步骤 1：启动 Python 爬虫服务（必需）

```bash
cd hospital-crawler
pip install -r requirements_simple.txt
python app_simple.py
```

**确认看到以下输出**：
```
==================================================
医院信息爬虫服务启动中（简化版）...
==================================================
服务地址: http://localhost:5000
健康检查: GET /api/health
搜索医院: GET/POST /api/hospital/search
获取医院详情: POST /api/hospital/detail
按位置搜索: POST /api/hospital/nearby
==================================================
```

### 步骤 2：验证 Python 服务

在浏览器访问：
```
http://localhost:5000/api/health
```

应该返回：
```json
{
  "status": "ok",
  "message": "医院信息爬虫服务正常运行（简化版）"
}
```

### 步骤 3：确保 Java 后端运行

```bash
cd hospital-api
mvn spring-boot:run
```

### 步骤 4：在微信开发者工具中测试

1. 打开微信开发者工具
2. 确保已勾选「不校验合法域名」
3. 点击「编译」
4. 进入「周边医院」页面
5. 应该能看到地图和医院列表！

### 地图功能

### 医院列表功能
- 📞 一键拨号
- 🚑 急诊电话

## ⚠️ 注意事项

### 1. 必须启动 Python 爬虫服务
小程序直接调用 `http://localhost:5000`，**必须先启动 Python 服务**！

### 2. 微信开发者工具设置
必须勾选「不校验合法域名、web-view、TLS 版本」：
1. 点击右上角「详情」
2. 「本地设置」标签
3. ✓ 勾选「不校验合法域名...」

### 3. 位置权限
首次进入需要授权位置权限！
