# 微信小程序功能调试指南

## 功能无法正常工作的常见原因

### 1. 后端服务未启动 ⭐ 最常见

**症状**：
- 首页不显示科室和医生列表
- 周边医院无法加载
- 所有网络请求都失败

**检查方法**：
1. 打开浏览器访问：`http://localhost:8080`
2. 如果无法访问，说明后端服务未启动

**解决方法**：
```bash
# 打开新的终端，进入 hospital-api 目录
cd hospital-api

# 启动 Spring Boot 后端
mvn spring-boot:run

# 或者如果你已经编译过了
java -jar target/hospital-api-0.0.1-SNAPSHOT.jar
```

---

### 2. Python 爬虫服务未启动

**症状**：
- 周边医院无法获取急诊电话和预约链接

**检查方法**：
1. 打开浏览器访问：`http://localhost:5000/api/health`
2. 如果无法访问，说明爬虫服务未启动

**解决方法**：
```bash
# 打开新的终端，进入 hospital-crawler 目录
cd hospital-crawler

# 安装依赖（如果还没安装）
pip install -r requirements.txt

# 启动爬虫服务
python app.py
```

---

### 3. 微信开发者工具控制台错误

**检查方法**：
1. 在微信开发者工具中，点击「调试器」标签
2. 查看「Console」标签页是否有红色错误信息

**常见错误及解决方案**：

#### 错误 1：`request:fail` 网络请求失败
**原因**：后端服务未启动，或域名未配置
**解决**：
- 确认后端服务在 `http://localhost:8080` 运行
- 在开发者工具「详情」→「本地设置」中，勾选：
  ✓ 不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书

#### 错误 2：`getLocation:fail` 位置获取失败
**原因**：用户未授权位置权限
**解决**：
- 在模拟器中，点击「地理位置」模拟位置
- 或者在真机上测试

#### 错误 3：页面跳转失败
**原因**：页面路径错误，或页面未注册
**解决**：
- 检查 `app.json` 中的 pages 数组是否包含所有页面
- 确认跳转路径正确

---

### 4. 检查控制台输出

**在微信开发者工具中查看网络请求**：
1. 点击「调试器」→「Network」标签
2. 点击页面上的功能按钮
3. 查看是否有请求发出
4. 点击请求查看详情：
   - **Status**：HTTP 状态码（200 表示成功）
   - **Request**：发送的数据
   - **Response**：返回的数据

---

### 5. 测试各个功能的步骤

#### 测试首页功能
1. 启动后端服务
2. 在开发者工具中编译小程序
3. 查看首页是否显示科室和医生
4. 点击「预约挂号」等按钮，测试跳转

#### 测试周边医院功能
1. 确保后端和爬虫服务都已启动
2. 点击「周边医院」标签
3. 授权位置权限（或在模拟器中设置位置）
4. 查看是否加载医院列表
5. 点击「拨号」按钮测试电话功能

#### 测试预约功能
1. 先在「我的」页面登录
2. 点击「预约挂号」
3. 按步骤选择科室、医生、时间
4. 提交预约

### 7. 常见问题解答

**Q: 为什么点击按钮没有反应？**
A: 检查以下几点：
1. 按钮的 `bindtap` 是否正确绑定
2. JS 文件中是否有对应的函数
3. 控制台是否有错误

**Q: 为什么数据不显示？**
A: 检查：
1. 后端服务是否启动
2. Network 标签中是否有请求
3. 请求返回的数据格式是否正确

**Q: 为什么位置获取失败？**
A: 
- 在模拟器中：点击「地理位置」→ 选择或输入坐标
- 在真机上：确保已授权位置权限
