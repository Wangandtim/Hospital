# 微信小程序问题修复说明

## 已修复的问题

### 1. WXML 编译错误 - 可选链操作符问题

**错误信息**：
```
Bad value with message: unexpected token `.`
```

**原因**：微信小程序的 WXML 不支持 JavaScript 的可选链操作符 (`?.`)

**修复的文件**：
- `pages/appointment/appointment.wxml:13`
- `pages/appointment/appointment.wxml:28`
- `pages/my-appointments/my-appointments.wxml:20`
- `pages/my-appointments/my-appointments.wxml:24`

**修复方法**：
将可选链操作符替换为传统的条件判断：
- 原来：`{{selectedDept?.deptId === item.deptId ? 'selected' : ''}}`
- 修复后：`{{selectedDept && selectedDept.deptId === item.deptId ? 'selected' : ''}}`

- 原来：`{{item.department?.deptName || '-'}}`
- 修复后：`{{item.department && item.department.deptName ? item.department.deptName : '-'}}`

### 2. TabBar 图标缺失问题

**错误信息**：
```
app.json: ["tabBar"]["list"][0]["iconPath"]: "images/home.png" 未找到
```

**临时解决方案**：
已修改 `app.json`，暂时移除了所有图标配置，只保留文字标签。

**当前 TabBar 配置**：
```json
"tabBar": {
  "list": [
    { "pagePath": "pages/index/index", "text": "首页" },
    { "pagePath": "pages/nearby/nearby", "text": "周边医院" },
    { "pagePath": "pages/my-appointments/my-appointments", "text": "我的预约" },
    { "pagePath": "pages/profile/profile", "text": "我的" }
  ]
}
```

**如何添加图标（可选）**：
1. 准备 8 个图标文件（4个普通状态 + 4个选中状态）
2. 放入 `images/` 目录
3. 在 `app.json` 中重新添加 `iconPath` 和 `selectedIconPath` 配置

### 3. "启动组件需要按需注入"问题

**说明**：这个提示通常不是错误，而是微信开发者工具的一个提示信息。

**已优化配置**：
已更新 `project.config.json`，添加了以下配置：
- `lazyloadPlaceholderEnable`: false - 禁用懒加载占位符
- `urlCheck`: false - 关闭域名检查（开发阶段）
- `coverView`: true - 启用 cover-view
- 其他常用配置项

**如果仍然看到此提示**：
1. 在微信开发者工具中，点击「详情」
2. 找到「本地设置」
3. 确保以下选项已正确设置：
   - ✓ 不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书
   - ✓ ES6 转 ES5
   - ✓ 增强编译
