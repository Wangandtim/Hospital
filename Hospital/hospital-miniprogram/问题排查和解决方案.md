# 微信小程序空白问题排查和解决方案

## 问题诊断结果

✅ **后端服务正在运行** - 端口 8080 正常服务中  
✅ **科室 API 正常** - `/api/departments` 有数据返回  
❌ **医生 API 为空** - `/api/doctors` 返回 `[]` 空数组  
❌ **排班数据缺失** - 医生和排班表没有数据

## 原因分析

`DataInitializer.java` 只会在数据库完全为空时才初始化数据。现在：
- 科室表（department）已有数据 → 初始化停止
- 医生表（doctor）为空 → 没有数据
- 排班表（schedule）为空 → 没有数据
- 患者表（patient）为空 → 没有数据

## 解决方案

### 方案 1：清空数据库重新初始化（推荐）

#### 步骤 1：停止现有后端
```bash
# 找到占用 8080 的进程
netstat -ano | findstr :8080
# 强制终止（替换 PID 为实际的进程号）
taskkill /F /PID <进程号>
```

#### 步骤 2：清空数据库表
使用 MySQL 客户端或 Navicat 等工具，连接到数据库 `hospital_db`，执行：

```sql
-- 清空所有表（按顺序避免外键约束问题）
DELETE FROM appointment;
DELETE FROM schedule;
DELETE FROM doctor;
DELETE FROM patient;
DELETE FROM department;
DELETE FROM wechat_user;
DELETE FROM nearby_hospital;
```

或者直接删除并重建数据库：
```sql
DROP DATABASE IF EXISTS hospital_db;
CREATE DATABASE hospital_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

#### 步骤 3：重新启动后端
```bash
cd hospital-api
mvn spring-boot:run
```

启动时应该看到：
```
========================================
开始初始化西安欧亚学院门诊部数据...
========================================
✓ 科室数据初始化完成（7个科室）
✓ 医生数据初始化完成（8位医生）
✓ 患者数据初始化完成（2位测试患者）
✓ 排班数据初始化完成（20条排班）
========================================
西安欧亚学院门诊部数据初始化完成！
========================================
```

## 微信小程序配置检查

### 1. 确保微信开发者工具设置正确

打开微信开发者工具：
- 点击右上角「详情」
- 找到「本地设置」标签
- **务必勾选**：
  - ✓ 不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书

### 2. 检查网络请求

在微信开发者工具中：
- 打开「调试器」→「Network」
- 刷新小程序页面
- 查看是否有请求发出到 `http://localhost:8080`
- 查看请求的响应内容

### 3. 查看控制台错误

在微信开发者工具中：
- 打开「调试器」→「Console」
- 查看是否有红色错误信息
