- home-active.png - 首页图标（选中）
- location.png - 周边医院图标（未选中）
- location-active.png - 周边医院图标（选中）
- calendar.png - 我的预约图标（未选中）
- calendar-active.png - 我的预约图标（选中）
- user.png - 个人中心图标（未选中）
- user-active.png - 个人中心图标（选中）
