# 微信小程序加载失败 - 详细调试步骤

## 🔴 重要：必须先做的配置

### 1. 关闭域名校验（最重要！）

打开微信开发者工具：

1. 点击右上角 **「详情」** 按钮
2. 找到 **「本地设置」** 标签页
3. **必须勾选以下选项**：
   - ✅ **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**

**这个是最常见的问题！** 如果不勾选，localhost 请求会被拦截！

***

### 2. 查看网络请求

在微信开发者工具中：

1. 点击底部 **「调试器」** 按钮
2. 找到 **「Network」** 标签
3. 刷新小程序页面（点击「编译」按钮）
4. 查看是否有请求发出到 `http://localhost:8080`
5. 点击每个请求，查看：
   - 请求是否成功（状态码 200）
   - 响应内容是什么
   - 有没有错误信息

***

### 3. 查看控制台错误

在微信开发者工具中：

1. 点击底部 **「调试器」** 按钮
2. 找到 **「Console」** 标签
3. 刷新小程序页面
4. 查看是否有红色错误信息
5. 把错误信息告诉我！

***

## 📋 快速检查清单

- [ ] 后端服务正在运行？（浏览器访问 <http://localhost:8080/api/departments> 测试）
- [ ] 微信开发者工具已勾选「不校验合法域名」？
- [ ] Network 标签有请求发出吗？
- [ ] Console 标签有红色错误吗？

***

## 🧪 手动测试 API

用浏览器直接访问以下链接，确认后端正常：

1. **科室列表**：<http://localhost:8080/api/departments>
2. **医生列表**：<http://localhost:8080/api/doctors>

应该都能看到 JSON 数据！

***

## 🔍 常见问题和解决

### 问题 1：请求被拦截（无网络请求）

**原因**：没有勾选「不校验合法域名」\
**解决**：按步骤 1 操作

### 问题 2：Network 显示红色错误

**原因**：后端没启动或端口不对\
**解决**：确认后端在 8080 端口运行

### 问题 3：Console 有 JS 错误

**原因**：代码问题\
**解决**：把错误信息发给我
