# 医院预约系统 - 用户故事与需求分析
====================================

## 🎯 三类用户核心诉求

---

### 👤 患者 (Patient) - 核心诉求

1. **便捷预约挂号**
   - 快速找到合适的科室和医生
   - 选择方便的就诊时间
   - 预约流程简单直观

2. **查询和管理预约**
   - 查看已预约的记录
   - 取消预约（在允许的时间内）
   - 查看预约状态变化

3. **了解医生信息**
   - 查看医生的专业背景和特长
   - 了解医生的职称和经验
   - 选择最适合的医生

4. **查看科室信息**
   - 了解科室的诊疗范围
   - 查看科室的门诊时间

---

### 👨‍⚕️ 医生 (Doctor) - 核心诉求

1. **查看预约记录**
   - 查看当天的预约患者列表
   - 了解患者的基本信息
   - 查看预约时间段

2. **管理预约状态**
   - 标记患者已就诊
   - 处理患者爽约情况
   - 查看历史就诊记录

3. **个人信息管理**
   - 查看和编辑个人简介
   - 更新专业特长信息
   - 设置可预约的时间

---

### 🛠️ 管理员 (Administrator) - 核心诉求

1. **用户管理**
   - 管理医生账号
   - 管理患者账号
   - 分配角色和权限

2. **科室管理**
   - 添加、编辑、删除科室
   - 维护科室信息
   - 设置科室排班

3. **医生管理**
   - 添加、编辑、删除医生
   - 分配医生到科室
   - 设置医生职称和信息

4. **预约管理**
   - 查看所有预约记录
   - 处理异常预约
   - 生成预约统计报表

5. **数据统计**
   - 查看就诊量统计
   - 分析科室/医生预约情况
   - 生成运营报表

---

## 📖 8个用户故事 (User Stories)

---

### 患者相关 (4个)

#### 用户故事 1：患者预约挂号
**作为** 一名患者
**我想要** 在微信小程序中选择科室、医生和时间进行预约
**这样我** 就能方便地挂号就诊，避免排队等待

**验收标准**：
- [ ] 可以浏览所有科室列表
- [ ] 可以查看科室下的医生列表
- [ ] 可以选择预约日期和时间段
- [ ] 可以确认预约信息并提交
- [ ] 预约成功后有提示并跳转到我的预约

---

#### 用户故事 2：患者查看预约记录
**作为** 一名患者
**我想要** 在小程序中查看我的所有预约记录
**这样我** 就能清楚知道什么时候需要去医院就诊

**验收标准**：
- [ ] 可以查看所有预约记录
- [ ] 可以按状态筛选（待就诊/已完成/已取消）
- [ ] 可以看到预约的医生、科室、时间信息
- [ ] 状态清晰易读

---

#### 用户故事 3：患者取消预约
**作为** 一名患者
**我想要** 在就诊前一天取消我的预约
**这样我** 就能灵活安排时间，不浪费医疗资源

**验收标准**：
- [ ] 在就诊前24小时以上可以取消
- [ ] 取消时需要确认提示
- [ ] 取消后状态更新为"已取消"
- [ ] 就诊前24小时内不允许取消

---

#### 用户故事 4：患者查看医生详情
**作为** 一名患者
**我想要** 查看医生的详细信息
**这样我** 就能选择最适合我的医生就诊

**验收标准**：
- [ ] 可以查看医生的姓名、职称
- [ ] 可以查看医生的专业特长
- [ ] 可以查看医生所在科室
- [ ] 可以直接从医生详情页发起预约

---

### 医生相关 (2个)

#### 用户故事 5：医生查看当天预约
**作为** 一名医生
**我想要** 查看当天预约我的患者列表
**这样我** 就能提前做好看诊准备

**验收标准**：
- [ ] 可以查看当天预约的所有患者
- [ ] 可以看到患者的预约时间段
- [ ] 可以看到患者的基本信息
- [ ] 可以按时间段排序

---

#### 用户故事 6：医生标记就诊完成
**作为** 一名医生
**我想要** 标记患者已完成就诊
**这样** 预约状态就能及时更新

**验收标准**：
- [ ] 可以点击"完成就诊"按钮
- [ ] 确认后状态更新为"已完成"
- [ ] 记录完成时间
- [ ] 已完成的预约不能再修改

---

### 管理员相关 (2个)

#### 用户故事 7：管理员管理医生信息
**作为** 一名管理员
**我想要** 添加、编辑和删除医生信息
**这样我** 就能维护医院的医生团队

**验收标准**：
- [ ] 可以添加新医生
- [ ] 可以编辑医生信息（姓名、职称、科室、专长等）
- [ ] 可以删除医生（软删除）
- [ ] 可以分配医生到不同科室

---

#### 用户故事 8：管理员查看预约统计
**作为** 一名管理员
**我想要** 查看医院的预约统计数据
**这样我** 就能了解医院的运营情况

**验收标准**：
- [ ] 可以查看总预约量
- [ ] 可以查看各科室预约量
- [ ] 可以查看各医生预约量
- [ ] 可以按日期范围筛选统计

---

## ⚠️ 缺失但必须的功能

---

### 1. 用户认证与权限管理
**现状**：目前只有简化的微信登录，没有完整的权限管理

**必须添加**：
- [ ] 用户角色区分（患者/医生/管理员）
- [ ] 基于角色的权限控制
- [ ] 医生端登录入口
- [ ] 管理员端登录入口
- [ ] 登录状态保持

---

### 2. 医生端管理后台
**现状**：目前只有患者端小程序

**必须添加**：
- [ ] 医生端登录页面
- [ ] 医生工作台首页
- [ ] 我的预约列表
- [ ] 患者详情查看
- [ ] 个人信息设置

---

### 3. 管理员管理后台
**现状**：目前没有管理员端

**必须添加**：
- [ ] 管理员登录页面
- [ ] 管理员工作台
- [ ] 科室管理模块
- [ ] 医生管理模块
- [ ] 预约管理模块
- [ ] 数据统计模块

---

### 4. 排班管理
**现状**：目前只有简单的时间选择，没有实际排班表

**必须添加**：
- [ ] 医生排班设置
- [ ] 可预约时间管理
- [ ] 号源管理（每个时间段的号数）
- [ ] 停诊/出诊设置
- [ ] 排班冲突检测

---

### 5. 号源管理
**现状**：预约不检查号源是否充足

**必须添加**：
- [ ] 每个时间段设置最大预约数
- [ ] 预约时检查号源是否充足
- [ ] 号源不足时提示
- [ ] 实时显示剩余号源

---

### 6. 患者信息完善
**现状**：患者信息不完整

**必须添加**：
- [ ] 患者基本信息填写（姓名、性别、年龄、电话）
- [ ] 病史信息记录
- [ ] 身份证号（可选）
- [ ] 医保卡信息（可选）
- [ ] 紧急联系人信息

---

### 7. 消息通知
**现状**：没有消息通知功能

**必须添加**：
- [ ] 预约成功通知
- [ ] 预约取消通知
- [ ] 就诊提醒（提前1天/1小时）
- [ ] 停诊通知
- [ ] 医生端新预约提醒

---

### 8. 评价反馈
**现状**：没有评价功能

**必须添加**：
- [ ] 就诊完成后可以评价医生
- [ ] 评价星级（1-5星）
- [ ] 文字评价
- [ ] 医生查看患者评价

---

### 9. 数据安全与备份
**现状**：没有明确的数据安全机制

**必须添加**：
- [ ] 数据定期备份
- [ ] 敏感数据加密
- [ ] 操作日志记录
- [ ] 数据恢复机制

---

### 10. 支付功能（可选但推荐）
**现状**：挂号费为0元，没有实际支付

**推荐添加**：
- [ ] 微信支付集成
- [ ] 支付记录查询
- [ ] 退款功能
- [ ] 发票功能

---
